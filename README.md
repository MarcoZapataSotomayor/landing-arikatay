# Ari Katay

Landing de Ari Katay construida con React, TypeScript, Vite, Tailwind CSS y Framer Motion.

## Desarrollo

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```

El catálogo y el carrito viven en `src/App.tsx`. El pedido abre un mensaje prellenado al WhatsApp configurado en `WHATSAPP_NUMBER`.
